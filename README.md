### [EcoTrack](https://github.com/EcoTrackEnvironment/EcoTrack) · Motiva (CCR) Challenge

Vegetation monitoring for the Rodoanel Mário Covas ring road, in São Paulo. It combines climate data, Machine Learning forecasting, and an agronomic simulation to estimate grass growth and plan mowing. Made it to **Next**, FIAP's main tech event.

> **My part:** front-end and team management, organizing deliveries with Scrum and Trello.

### [SmartSolarGrid](https://github.com/jumarques03/SmartSolarGrid-Challenge2025) · FIAP Challenge with Goodwe

Solar home automation with Goodwe inverters, the Alexa virtual assistant, and a web platform to monitor and control energy use in real time. Made it to **Next**, FIAP's main tech event.

> **My part:** the Python backend and API that connect the website and the Alexa skill, the energy consumption charts, and a chatbot built on the Gemini API.
